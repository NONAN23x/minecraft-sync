# Minecraft Sync Migration Status

The original Python-first plan in this file has been superseded.

## Current State

- The primary installer is now Rust in `src/main.rs`.
- Release archives and `manifest.json` are generated by `scripts/release.py`.
- GitHub Releases are published automatically by `.github/workflows/release.yml` when a `v*` tag is pushed.
- `main.py` is a deprecated legacy workflow and is no longer the supported distribution path.

## Release Outcome

- Users download installer binaries from GitHub Releases.
- The installer fetches `manifest.json`, verifies downloaded release assets, installs Fabric, and syncs pack content into `.minecraft`.
- The repository remains the source of truth for pack folders and the Fabric installer jar.
